# Strata documentation

Start with the active documents below. [The status ledger](status.md) is the implementation source of truth; use it over legacy phase numbers or historical mechanism notes. The architecture and how-it-works narratives are explanatory navigation and must be read together with the ledger and the current Phase 1 audit.

1. [Status ledger](status.md) — evidence-backed implementation boundaries and known gaps.
2. [Capability roadmap](roadmap.md) — the current Phase 0–6 plan and exit criteria.
3. [Architecture](architecture.md) — system shape and component boundaries.
4. [How Strata works](how-strata-works.md) — end-to-end operational explanation.
5. [Conventions](conventions.md) and [decision index](decisions/README.md) — contribution rules and governing decisions.
6. [Agent guidance](../AGENTS.md) — repository workflow, invariants, and verification expectations.

## Active versus history

The files above are the active navigation layer. [History](history/README.md) preserves prior ADRs, designs, and analyses for rationale, but is non-authoritative when it conflicts with active documentation, current source, or tests. Historical phase numbering is not the current roadmap.

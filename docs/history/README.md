# Documentation history

This folder preserves rationale and dated context that no longer belongs in the active reading path.
It is non-authoritative: use current source, tests, and the canonical documents in `docs/` for behavior.

- [Decisions](decisions.md) - superseded ADRs and decision chronology.
- [Designs](designs.md) - retired proposals, phase plans, and implementation transitions.
- [Audits](audits.md) - older audits and bounded measurements.
- [Engineering notes](engineering-notes.md) - dated implementation-plan outcomes and process notes.

The former per-document archive was intentionally collapsed. Git history retains the original files,
while these summaries keep the rationale, dates, PR references, and warnings needed by future readers.
